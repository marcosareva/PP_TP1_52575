PROYECTO DE EVENTOS UNIVERSITARIOS 
Hecho por Arevalo, Marcos

Este proyecto permite crear una lista de estudiantes y crear un eventos universitarios, el cual puede tener una o más 
actividades (charlas o talleres) y una sala existente asignada. Cada actividad tiene una lista de inscripciones que 
cuenta con estudiantes. Los datos de los eventos creados son mostrados por 
pantalla junto con un contador de del total de eventos registrados.

Para EJECUTAR este proyecto:
Abrir IntelliJ IDEA y ejecutar desde el archivo "app" (PP_TP1_52575\Proyecto Eventos Univeritarios\src/app.java).

Se adjunta el DIAGRAMA DE CLASES en la misma carpeta.
